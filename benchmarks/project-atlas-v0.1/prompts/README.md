# Prompt Publication Status

The benchmark stage descriptions and expected-state logic are documented in this package, but **the full raw prompt transcript is not included in this export yet**.

Before describing this benchmark as fully reproducible, add the exact verbatim prompt sequence used for both Native and Root conditions.

Recommended structure:

- `stage-00.md`
- `stage-01.md`
- `stage-02.md`
- `stage-03.md`
- `stage-04.md`
- `stage-05.md`
- `stage-06.md`

Each file should contain:

1. all update prompts that preceded the verification,
2. the exact verification prompt,
3. a note confirming that the same prompt text was sent to both compared conditions,
4. model/reasoning settings,
5. execution order,
6. UI-reported thinking time if recorded.

Do not reconstruct missing prompts from memory. Use verbatim chat exports/screenshots/transcripts where possible.
